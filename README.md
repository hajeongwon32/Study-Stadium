# Study Stadium 실행 및 테스트 안내

## 1. 실행 방법

### 배포 사이트에서 실행

**[Study Stadium 접속하기](https://genuine-gelato-e7c032.netlify.app/)**

별도 설치 없이 위 링크에 접속한 뒤, 아래 테스트 계정으로 로그인합니다.

### 소스 코드로 실행

1. VS Code에서 프로젝트 폴더를 엽니다.
2. VS Code 확장 프로그램 **Live Server**를 설치합니다.
3. 프로젝트 최상위 `index.html`을 우클릭하고 **Open with Live Server**를 선택합니다.
4. 열린 로그인 화면에서 아래 테스트 계정으로 로그인합니다.

> 인터넷 연결이 필요합니다. 별도 패키지 설치나 빌드는 필요하지 않습니다. HTML 파일을 더블 클릭하지 말고 Live Server로 실행하세요.

## 2. 테스트 계정

| 항목 | 계정 정보 |
| --- | --- |
| 닉네임 | `test` |
| 비밀번호 | `123456` |

> 로그인에는 이메일이 아닌 **닉네임**을 사용합니다. 위 계정 정보는 대괄호 없이 입력하세요.

직접 계정을 만들려면 로그인 화면에서 **회원가입 → 닉네임 중복 확인 → 비밀번호 입력(6자리 이상) → 선수 등록** 순서로 진행합니다.

## 3. 테스트 방법

| 순서 | 조작 방법 | 확인할 내용 |
| --- | --- | --- |
| 1 | 테스트 계정으로 로그인 | 메인 화면으로 이동 |
| 2 | **경기하러 가기 → 시간 설정 → 1분 → 저장** | 타이머가 01:00으로 표시 |
| 3 | **시작 → 일시정지 → 계속하기** | 타이머 정지 및 재개 |
| 4 | 집중 시간 1분 완료 | 1세트 저장 후 5분 휴식 자동 시작 |
| 5 | 휴식 종료까지 대기 | 다음 집중 세트 자동 시작 |
| 6 | 집중 중 **오늘은 여기까지 → 노트 입력 → 저장하고 종료** | 공부 기록과 노트 저장, 경기 종료 |
| 7 | 메인 화면으로 돌아가 **오늘 날짜** 선택 | 경기 리포트에서 세트 수·집중 시간·노트 확인 |
| 8 | **STUDY STATS** 선택 | 누적 세트·집중 시간·연속 공부 일수 확인 |

**빠르게 확인하려면:** 3번 이후 바로 **오늘은 여기까지**를 눌러 6~8번을 진행하면 됩니다. 이 경우 자동 휴식 전환 확인은 생략됩니다.

### 테스트 시 참고 사항

- **오늘 경기를 종료했거나 4세트를 완료한 계정은 같은 날 다시 시작할 수 없습니다.** 타이머를 다시 테스트하려면 오늘 경기를 종료하지 않은 다른 계정을 사용하세요.
- **오늘은 여기까지**는 집중 세트를 시작한 뒤 사용할 수 있습니다. 진행 중인 세트도 1세트로 집계하고, 공부 시간은 최소 1분으로 기록합니다.
- 진행 중인 세트에서 페이지를 떠나면 해당 세트는 저장되지 않습니다.
